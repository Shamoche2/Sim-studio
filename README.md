# Sim Studio

Teachers type a topic ("projectile motion", "phases of the moon", "supply and demand"), pick a grade level, and get an interactive classroom simulation generated by Claude. They can then ask for changes in plain words, keep simulations in a library, and share a full-screen link with students.

## Quick start

Requires Node.js 22 or newer.

```bash
cd sim-generator
npm install
cp .env.example .env      # then paste your key from https://console.anthropic.com
npm start                 # open http://localhost:3000
```

Without an API key the app runs in **demo mode**: the two built-in samples (projectile motion, predator-prey populations) work, and any other topic shows a message explaining how to connect the key.

## How it works

| Piece | File | What it does |
|---|---|---|
| Teacher UI | `public/` | Topic form, live progress, sandboxed preview, "ask for a change" box, library, share links |
| API server | `server.js` | `POST /api/generate` streams progress as newline-delimited JSON; `/sim/:id` serves the student link |
| Generation | `lib/generate.js` | Calls Claude with a detailed simulation-design prompt, streams the output, retries once if it's incomplete |
| Library | `lib/store.js` | Saves each simulation to `data/` and returns repeat requests (same topic and grade) instantly from cache |
| Samples | `samples/` | Hand-written example simulations used in demo mode |

**Safety.** Generated code runs in an `<iframe sandbox="allow-scripts">` with a Content-Security-Policy that blocks all network access, so a simulation can't load external content, send data anywhere, or touch the app itself. The student link (`/sim/:id`) is served with the same policy as an HTTP header.

**Model.** Uses `claude-opus-5-5` by default (override with `SIM_MODEL` in `.env`). Requests turn on server-side refusal fallbacks, so if a safety filter wrongly declines a topic, the request is retried automatically on a fallback model.

## Costs

Each new simulation is one API call: roughly 1–2k input tokens and 8–20k output tokens. At current Claude Opus 5.5 prices ($4 per million input tokens, $20 per million output tokens), that's about **$0.15–0.45 per simulation**. Revisions cost about the same, since the full page is rewritten. Repeated topics served from the library cost nothing. Check the server log, which prints the token counts for each generation.
